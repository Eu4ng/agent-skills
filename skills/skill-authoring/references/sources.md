# 근거 모으기

스킬의 가치는 에이전트가 스스로는 모르는 사실과 교정에서 나온다. 아래 순서로 찾는다.

## 먼저 볼 것

1. 지금 대화에서 사용자가 교정한 내용과 확정한 결정
2. 대상 저장소의 AGENTS.md, README, 기존 `.agents/skills/`
3. `git log -p` 중 되돌림(`revert`)·수정(`fix`) 커밋, 이슈·PR 리뷰 코멘트
4. 지난 세션 기록 (아래)

## 세션 기록 위치

도구마다 다르고 버전에 따라 바뀐다. 알려진 위치는 예시로만 쓰고, 파일을 몇 줄 열어 구조를 확인한 뒤 쓴다.

| 도구 | 위치(예) |
| :--- | :--- |
| Claude Code | `~/.claude/projects/<작업 폴더 경로를 - 로 바꾼 이름>/<세션>.jsonl`, 입력 기록 `~/.claude/history.jsonl` |
| Codex CLI | `~/.codex/sessions/<연>/<월>/<일>/rollout-*.jsonl` |
| 그 밖의 도구 | 해당 도구 문서에서 세션·기록 저장 위치를 확인한다 |

## 사용자 메시지 뽑기

JSONL 세션 기록에서 사람이 입력한 문장만 뽑는다. 도구 호출 결과와 시스템이 끼워 넣은 문장은 뺀다.

```bash
python3 scripts/user_messages.py ~/.claude/projects/<폴더>/*.jsonl --corrections --limit 200
```

- `--corrections`: 교정 신호가 있는 메시지만 남긴다. 예: "아니", "이미", "왜", "했어야지", "말고", "그게 아니라",
  "no,", "actually", "instead", "should have".
- `--grep <정규식>`: 주제어로 거른다. 예: `--grep '토큰|secret'`
- `--context 1`: 각 메시지 앞의 에이전트 응답 요약(텍스트 앞부분)을 붙인다. 무엇을 잘못했는지 볼 때 쓴다.

출력은 한 줄에 하나씩 `{"file", "line", "time", "text", "before"}` JSON 이다.

## 교정을 스킬 문장으로 바꾸기

같은 교정이 두 번 이상 나오면 스킬에 넣을 후보다. 교정 하나를 다음처럼 바꾼다.

| 교정(원문) | 스킬 문장 |
| :--- | :--- |
| "토큰 넣어놨잖아. 서버에 있을 텐데" | `## 주의`: 토큰은 사용자에게 묻기 전에 `~/.agents/environment.md` 의 시크릿 위치에서 찾는다 |
| "내가 지정한 것만 보지 말고 전부 적용했어야지" | 절차: 규칙을 적용할 때 같은 종류의 항목 전체를 찾아 함께 적용한다 |
| "관련 문서도 고쳤어?" | 검증 단계: 바꾼 대상을 설명하는 문서를 찾아 같이 고친다 |

환경 고유값(호스트, 시크릿 이름 등)은 스킬이 아니라 `~/.agents/environment.md` 에 옮긴다.
