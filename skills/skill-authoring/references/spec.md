# Agent Skills 표준 요점

오프라인에서도 볼 수 있게 표준의 필요한 부분만 옮겼다(2026-08 판 기준).

## 폴더 구조

```
<이름>/
├── SKILL.md          # 필수: frontmatter + 지시
├── scripts/          # 선택: 실행할 코드
├── references/       # 선택: 필요할 때 읽을 문서
├── assets/           # 선택: 템플릿, 데이터 파일
└── ...               # 그 밖의 파일도 둘 수 있다
```

## frontmatter

`SKILL.md` 는 `---` 로 감싼 YAML frontmatter 로 시작하고 마크다운 본문이 뒤따른다.

| 필드 | 필수 | 제약 |
| :--- | :--- | :--- |
| `name` | 예 | 1~64자. 소문자·숫자·하이픈. 하이픈으로 시작·끝나거나 연달아 쓸 수 없다. 부모 폴더 이름과 같아야 한다 |
| `description` | 예 | 1~1024자. 무엇을 하는지와 언제 쓰는지 |
| `license` | 아니오 | 라이선스 이름이나 함께 든 라이선스 파일 이름 |
| `compatibility` | 아니오 | 1~500자. 필요한 환경(제품, 시스템 패키지, 네트워크) |
| `metadata` | 아니오 | 문자열 키 → 문자열 값 매핑 |
| `allowed-tools` | 아니오 | 미리 허용할 도구를 공백으로 구분. 실험 단계라 도구마다 지원이 다르다 |

이 밖의 필드는 표준 검사기가 오류로 본다.

## 점진적 공개

1. 메타데이터(약 100 토큰): 모든 스킬의 `name`·`description` 을 시작할 때 읽는다.
2. 지시(5000 토큰 미만 권장): 스킬이 켜지면 `SKILL.md` 본문 전체를 읽는다.
3. 자원(필요할 때): `scripts/`, `references/`, `assets/` 의 파일은 필요할 때만 읽는다.

`SKILL.md` 는 500줄 미만으로 유지한다. 다른 파일은 스킬 폴더 기준 상대 경로로 가리키고, `SKILL.md` 에서 한 단계
깊이까지만 참조한다.

## 스킬이 놓이는 곳

표준은 폴더 안의 형식만 정하고 위치는 정하지 않는다. 도구들이 함께 읽는 관례는 다음과 같다.

| 범위 | 위치 |
| :--- | :--- |
| 저장소 | `<저장소>/.agents/skills/<이름>/` |
| 사용자 | `~/.agents/skills/<이름>/` |

이름이 겹치면 저장소 스킬이 사용자 스킬보다 우선한다.

## 스킬이 켜지는 방식

도구마다 다음 두 방식 중 하나 이상을 쓴다. 어느 쪽이든 동작하도록 스킬 안의 경로는 스킬 폴더 기준 상대 경로로 쓴다.

- 파일 읽기: 목록에 적힌 `SKILL.md` 경로를 읽는다.
- 전용 도구: 스킬 이름으로 불러 본문을 받는다. 보통 frontmatter 를 뺀 본문, 스킬 폴더 경로, 함께 든 파일 목록을 준다.

## 검사

- 이 스킬의 `scripts/lint.py`: 표준 규칙과 작성 규칙을 함께 검사한다. 오프라인에서 동작한다.
- 표준 참조 검사기(온라인일 때): `uvx --from skills-ref agentskills validate <스킬 폴더>`
